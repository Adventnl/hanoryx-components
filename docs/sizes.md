# Measured sizes

Generated by `scripts/generate-sizes-doc.mjs` from `docs/generated/sizing.json`. Every entry was rendered **alone** in a parent 360, 768 and 1200 px wide (real Chromium, 16 px root, reduced motion on) and its own box measured. Sizes are `width×height` in px.

| Behaviour | Meaning |
| --- | --- |
| **fill** | width = the parent's width at every size |
| **capped** | follows the parent up to a maximum, then stops |
| **intrinsic** | the same width whatever the parent is (including a component capped below 360 px) |
| **fluid** | changes with the parent, but not one-to-one |

A component that is `intrinsic` and wider than a phone (**overflow** column) will scroll sideways in a 360 px parent. Fix it with a parent that scrolls or a layout that stacks — never by setting a width on the component.
